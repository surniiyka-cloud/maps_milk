# ТИАН-Трейд · Аналитика ОП Киров

Интерактивный прототип бизнес-аналитики подразделения: KPI, продажи, дебиторская задолженность, маркетинговая воронка, клиенты.

## Просмотр

Сайт — статический `index.html`. Для публикации в GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите `main` и `/(root)`, затем сохраните. После публикации сайт обычно доступен по адресу `https://surniiyka-cloud.github.io/maps_milk/`.

Также можно скачать `index.html` и открыть локально браузером. Никакая сборка не требуется.

## Данные

**Сейчас в интерфейсе только демонстрационные значения, не данные компании.** База данных и интеграция с 1С пока не подключены. Файл `index.html` содержит объект `sample` с тестовыми показателями. Раздел «Источники данных» позволяет импортировать тестовый JSON в память текущей вкладки без передачи файла на сервер.

Формат JSON: `{ "revenue": 12840000, "revenuePlan": 14000000, "debt": 4800000, "orders": 148, "clients": 67, "debtors": [{"name":"ООО Пример", "region":"Киров", "amount":450000, "days":21, "status":"danger", "manager":"Менеджер"}] }`.

## Интеграция с 1С

В production-версии необходим **защищённый серверный слой** между 1С и frontend. Сервер отвечает за авторизацию, обновление и нормализацию информации, управление правами доступа, аудит и отдачу агрегированных KPI. **Не публиковать** финансовые сведения, список должников или ключи 1С в публичном репозитории и в GitHub Pages в виде статических JSON.

## План развития

1. Привести данные двух рабочих Excel к единой модели метрик.
2. Уточнить справочник контрагентов, периодичность обновления и определения KPI.
3. Подключить серверное API 1С с авторизацией и разграничением прав.
4. Проверить расчёты и визуализацию на реальных данных.
